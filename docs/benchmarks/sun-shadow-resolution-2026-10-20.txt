Experiment / implementation
- Mode 0: original 2048 x 2048 sunlight depth target.
- Mode 1: 1024 x 1024 sunlight depth target, now the game default for trying.
- Applies to ALL sunlight casters, including town, vegetation, zombies/objects.
- Flashlight target remains 1024 in both modes; night views are controls.
- 75% fewer sunlight depth pixels, approximately quarter map storage; actual
  driver allocation/alignment varies. Geometry and 120 m receiver range unchanged.
- Projection texel-snapping uses the selected resolution. PCF already derives
  its offsets from textureSize. Small boundary caster changes are possible as
  the snapped light volume shifts; this is part of the real resolution change.
- Texture filtering/mipmap policy, alpha cutoff, card splitting, culling,
  batching and fixed sunlight lighting otherwise match. Original asset textures
  remain resident at full resolution and are not resized.
- Complete target replacement between frames is exception-safe; invalid sizes
  leave the current map available. No target allocations in timed frames.
- --sun-shadow-resolution 2048 restores the old size; 1024 is built default.

Assessment
Forest A/B total GPU reductions: about 28% and 34%; 100 m and unrestricted old
forest reductions about 27% each. These four forest views improved in all six
paired round averages. Clearing improved about 13%, also all six pairs. Town
has a smaller median gain and one slower pair; aerial essentially unchanged.
The full sunlight pass in Forest A changes 6.54 -> 2.50 ms; Forest B
6.45 -> 2.56 ms. Unlike the previous mip floor, this is a useful measured
reduction in the tested forest workload. CPU render may benefit from reduced
GPU backpressure; no CPU visibility algorithm was replaced.
Scope: static cameras, fixed daytime sun direction, current map/hardware.
Full gameplay AI/physics, moving shadow stability and other sun angles not
benchmarked. Some geometry is unlit or distant/fogged, limiting visible shadow
differences in these views. Do not infer globally unchanged shadow quality.

Captures / invariants
- Main camera tree counts, tree calls, tree camera triangles and town calls are
  identical between variants in all nine views. Light boundary membership can
  shift with the coarser stabilization grid, as noted above.
- Forest A, aerial, both old-forest interiors and both flashlight controls:
  pixel-identical captures. Forest B: 1,176 changed pixels; clearing: 612.
- Town: 20,733 pixels differ; only 67 differ by more than 16 in any RGB channel.
  Mean absolute RGB difference is 0.053 on the 0..255 scale.
- Before/after forest and town images and 1:1 crops visually inspected. Static
  quality differences are small in these views. Shadows are coarser by design;
  moving-camera quality and more exposed lit receivers need gameplay inspection.
